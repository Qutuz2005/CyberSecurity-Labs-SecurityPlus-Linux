# SecurityPlus & Linux Hands-On Labs 🛡️🐧

Welcome to my cybersecurity repository! This repository documents my practical labs and hands-on projects, directly connecting core **CompTIA Security+** theoretical concepts with real-world execution inside a **Linux (Kali Linux)** environment.

## 📂 What's Inside:
- **Cryptography & Data Confidentiality:** Practical demonstration of symmetric encryption using the **AES** algorithm via online tools and command-line execution using **OpenSSL (AES-256-CBC)**.
- **Data Integrity & Hashing:** Generating cryptographic fingerprints using **SHA-256** digests via OpenSSL to ensure file integrity and detect unauthorized changes.
- **Linux Security Operations:** Utilizing Linux CLI utilities (`nano`, OpenSSL, etc.) to manage files, perform cryptographic operations, and secure sensitive text data (`SafeSurf_file.txt`).

## 🎯 Objective:
The primary goal of this repository is to bridge the gap between security theory and practical application, reinforcing essential skills required for Security Operations (SOC) and defensive cybersecurity.
